## 🎨 Phong Cách Viết

### Ngôn Ngữ
- ✅ Tiếng Việt cho mô tả
- ✅ Tiếng Anh cho technical terms (component, state, API, v.v.)
- ✅ Code examples bằng tiếng Anh

### Code Examples
- ✅ Sử dụng ✅/❌ để phân biệt tốt/xấu
- ✅ Include complete examples
- ✅ Thêm comments giải thích WHY
- ✅ Show before/after

### Cấu Trúc
- ✅ Heading rõ ràng
- ✅ Bullet points ngắn gọn
- ✅ Tables cho so sánh
- ✅ Code blocks với syntax highlighting
